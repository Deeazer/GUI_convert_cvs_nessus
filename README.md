# Конвертер CSV в PDF/DOCX для отчетов по уязвимостям

Проект для конвертации CSV файлов с результатами сканирования уязвимостей в форматированные PDF и DOCX отчеты. Поддерживает выбор уровней риска (Critical, High, Medium, Low, Info), автоматический перевод на русский язык и создание профессиональных отчетов через удобный графический интерфейс.

## Требования

- Python 3.7 или выше (рекомендуется Python 3.8+)
- PyQt5 для графического интерфейса
- Все зависимости из `requirements.txt`

**Важно для Python 3.13:** Если вы используете Python 3.13, убедитесь, что используете обновленный `requirements.txt` с совместимыми версиями пакетов (особенно Pillow >= 10.0.0).

## Установка

### Вариант 1: Установка из исходного кода

1. Клонируйте репозиторий или скачайте проект:
```bash
git clone <repository_url>
cd convert_csv-master
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

### Вариант 2: Готовая версия (рекомендуется для конечных пользователей)

1. Скачайте готовый исполняемый файл `VulnerabilityReportConverter.exe` из раздела [Releases](https://github.com/yourusername/convert_csv/releases)
2. Запустите `VulnerabilityReportConverter.exe` (установка не требуется)

> **Примечание:** При первом запуске Windows может выдать предупреждение о неизвестном издателе. Это нормально, так как приложение не имеет цифровой подписи. Нажмите "Подробнее", затем "Выполнить в любом случае".

**Если возникают проблемы с установкой Pillow на Python 3.13:**

Проблема связана с тем, что старые версии Pillow не поддерживают Python 3.13. Попробуйте следующие решения:

**Решение 1: Установка через предкомпилированные wheel файлы**
```bash
# Сначала обновите pip и установите wheel
python -m pip install --upgrade pip wheel

# Установите Pillow и lxml отдельно (pip автоматически найдет совместимые версии)
pip install Pillow lxml

# Затем установите остальные зависимости
pip install -r requirements.txt
```

**Решение 2: Использование более новой версии Pillow**
```bash
# Установите последнюю версию Pillow, которая поддерживает Python 3.13
pip install --upgrade Pillow

# Затем установите остальные зависимости
pip install -r requirements.txt
```

**Решение 3: Если проблемы сохраняются, используйте Python 3.12 или 3.11**
Рекомендуется использовать Python 3.11 или 3.12 для лучшей совместимости со всеми зависимостями проекта.

**Важно:** Убедитесь, что файлы шрифтов `arial.ttf` и `arialbd.ttf` находятся в корневой директории проекта. Если их нет, скрипт будет использовать стандартные шрифты системы.

## Структура CSV файла

### Обязательные поля

CSV файл должен содержать следующие колонки в указанном порядке:

| Колонка | Название | Описание | Пример |
|---------|----------|----------|--------|
| 1 | **Host** | IP-адрес или доменное имя уязвимого хоста | `192.168.1.10` |
| 2 | **Port** | Номер порта уязвимой службы | `22`, `80`, `443` |
| 3 | **Name** | Название уязвимости или недостатка механизма защиты | `SSH Server Type and Version Information` |
| 4 | **Description** | Подробное описание уязвимости | `It is possible to obtain information about the remote SSH server...` |
| 5 | **Solution** | Рекомендации по устранению уязвимости | `Disable this service if you do not use it.` |
| 6 | **Risk Factor** | Уровень риска уязвимости | `Critical`, `High`, `Medium`, `Low`, `None` |

### Формат CSV

- **Кодировка:** UTF-8
- **Разделитель:** запятая (`,`)
- **Кавычки:** текстовые поля могут быть заключены в двойные кавычки (`"`)
- **Первая строка:** должна содержать заголовки колонок

### Пример CSV файла

```csv
Host,Port,Name,Description,Solution,Risk Factor
"192.168.1.10","22","SSH Server Type and Version Information","It is possible to obtain information about the remote SSH server by sending an empty authentication request.","Update SSH server to the latest version.","Critical"
"192.168.1.10","80","HTTP Server Detection","The remote host is running an HTTP server.","Ensure proper security configuration.","High"
"192.168.1.10","443","SSL/TLS Certificate Issues","The SSL certificate has expired.","Renew the SSL certificate.","High"
```

### Важные замечания по полям

#### Host (Колонка 1)
- **Обязательное поле:** Да
- **Формат:** IP-адрес (IPv4/IPv6) или доменное имя
- **Примеры:** `192.168.1.10`, `example.com`, `10.0.0.1`
- **Использование:** Объединяется с Port для создания поля "Уязвимые ресурсы"

#### Port (Колонка 2)
- **Обязательное поле:** Да
- **Формат:** Число от 0 до 65535
- **Примеры:** `22`, `80`, `443`, `0` (для трассировки)
- **Использование:** Объединяется с Host для создания поля "Уязвимые ресурсы"

#### Name (Колонка 3)
- **Обязательное поле:** Да
- **Формат:** Текст на английском языке
- **Описание:** Краткое название уязвимости
- **Ограничения:** Рекомендуется до 200 символов для лучшей читаемости
- **Использование:** Отображается в колонке "Уязвимость или недостаток механизма защиты"

#### Description (Колонка 4)
- **Обязательное поле:** Да
- **Формат:** Текст на английском языке, может содержать переносы строк
- **Описание:** Подробное описание уязвимости, включая технические детали
- **Ограничения:** 
  - Автоматически разбивается на части, если превышает 3000 символов
  - Поддерживает многострочный текст
- **Использование:** Отображается в колонке "Описание"

#### Solution (Колонка 5)
- **Обязательное поле:** Да (может быть `n/a` если решение не применимо)
- **Формат:** Текст на английском языке
- **Описание:** Рекомендации по устранению или снижению риска уязвимости
- **Примеры:** 
  - `Update to version X.X.X`
  - `Disable this service if you do not use it`
  - `n/a` (если решение не применимо)
- **Использование:** Отображается в колонке "Рекомендации"

#### Risk Factor (Колонка 6)
- **Обязательное поле:** Да
- **Допустимые значения:** 
  - `Critical` - Критический уровень риска
  - `High` - Высокий уровень риска
  - `Medium` - Средний уровень риска
  - `Low` - Низкий уровень риска
  - `None` - Риск отсутствует
  - `Risk Factor` - Заголовок колонки (только в первой строке)
- **Важно:** Скрипт обрабатывает **только** записи с `Critical` и `High`
- **Использование:** Определяет цветовую маркировку и порядок сортировки в отчете

## Особенности работы скрипта

### Фильтрация уязвимостей

Скрипт автоматически фильтрует и обрабатывает **только критические и высокие уязвимости**:
- `Critical` - отображаются первыми с красной маркировкой (#670101)
- `High` - отображаются вторыми с темно-красной маркировкой (#970101)
- `Medium` и `Low` - **игнорируются**

### Возможности

- **Графический интерфейс** с индикатором выполнения
- **Гибкая фильтрация** по уровням риска
- **Автоматический перевод** описаний уязвимостей на русский язык
- **Поддержка форматов** PDF и DOCX
- **Обработка ошибок** с понятными сообщениями
- **Пропуск перевода** для ускорения тестирования

## Обработка данных

1. **Объединение Host:Port** - создается поле "Уязвимые ресурсы"
2. **Удаление дубликатов** - одинаковые записи объединяются
3. **Сортировка** - сначала Critical, затем High
4. **Объединение одинаковых уязвимостей** - если одна и та же уязвимость найдена на нескольких хостах, они объединяются в одну строку
5. **Автоматический перевод** - весь текст переводится с английского на русский через Google Translate API

### Форматирование выходных файлов

#### DOCX формат
- Альбомная ориентация (29.7 x 21 см)
- Цветовая маркировка по уровню риска
- Повторяющаяся шапка таблицы на каждой странице
- Запрет разрыва строк между страницами

#### PDF формат
- Альбомная ориентация (A4 landscape)
- Цветовая маркировка по уровню риска
- Повторяющаяся шапка таблицы на каждой странице
- Использование шрифтов Arial (если доступны)

## Рекомендации по использованию

### Подготовка CSV файла

1. **Проверьте кодировку:** Убедитесь, что файл сохранен в UTF-8
2. **Проверьте структуру:** Убедитесь, что файл содержит все 6 обязательных колонок
3. **Проверьте заголовки:** Первая строка должна содержать точные названия колонок
4. **Проверьте данные:** Убедитесь, что в колонке "Risk Factor" есть значения `Critical` или `High`
5. **Размер файла:** Рекомендуется до 100MB для стабильной работы

### Оптимизация работы

1. **Интернет-соединение:** Скрипт использует Google Translate API, требуется стабильное интернет-соединение
2. **Время выполнения:** 
   - Для файлов с 50-100 записями: 2-5 минут
   - Для файлов с 100-500 записями: 5-15 минут
   - Для больших файлов (500+ записей): 15-30+ минут
3. **Прогресс перевода:** Скрипт показывает прогресс перевода в реальном времени
4. **Оптимизация перевода:** Задержки между запросами оптимизированы для ускорения процесса
5. **Пропуск перевода:** Для тестирования можно пропустить перевод, отредактировав `main.py`:
   ```python
   # В строке 633 замените:
   data = translate(data)
   # На:
   data = translate(data, skip_translation=True)
   ```

### Безопасность

Скрипт включает следующие меры безопасности:
- ✅ Защита от Path Traversal атак
- ✅ Валидация входных файлов
- ✅ Проверка размера файлов (максимум 100MB)
- ✅ Обработка ошибок и исключений
- ✅ Валидация структуры CSV

### Устранение проблем

#### Ошибка "Файл не найден"
- Убедитесь, что CSV файл находится в той же папке, что и `main.py`
- Проверьте правильность имени файла (с учетом регистра)
- Убедитесь, что файл имеет расширение `.csv`

#### Ошибка "CSV файл должен содержать минимум 6 колонок"
- Проверьте структуру CSV файла
- Убедитесь, что все строки содержат данные во всех 6 колонках
- Проверьте правильность разделителей (запятые)

#### Ошибка "Не найдено критических или высоких уязвимостей"
- Проверьте значения в колонке "Risk Factor"
- Убедитесь, что используются точные значения: `Critical` или `High` (с учетом регистра)
- Проверьте, что первая строка содержит заголовок `Risk Factor`, а не данные

#### Ошибки перевода
- Проверьте интернет-соединение
- Убедитесь, что Google Translate API доступен
- При частых ошибках увеличьте задержку в функции `translate()` (строка с `time.sleep(0.1)`)
- Используйте опцию "Пропустить перевод" для тестирования без перевода
