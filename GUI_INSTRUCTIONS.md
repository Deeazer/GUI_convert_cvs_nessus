# Инструкция по использованию графического интерфейса

## Запуск приложения

Для запуска графического интерфейса выполните:

```bash
python gui.py
```

## Использование

### 1. Выбор входного файла
- Нажмите кнопку "Обзор..." рядом с полем "Входной файл"
- Выберите CSV файл с результатами сканирования уязвимостей

### 2. Выбор уровней уязвимостей
Отметьте галочками уровни уязвимостей, которые нужно включить в отчет:
- **Critical (Критический)** - по умолчанию включен
- **High (Высокий)** - по умолчанию включен
- **Medium (Средний)** - по умолчанию выключен
- **Low (Низкий)** - по умолчанию выключен
- **Info (Информационный)** - по умолчанию выключен
- **None (Отсутствует)** - по умолчанию выключен

### 3. Выбор формата выходного файла
- Выберите формат из выпадающего списка: **DOCX** или **PDF**

### 4. Указание выходного файла
- Введите имя выходного файла в поле "Выходной файл"
- Или нажмите "Обзор..." для выбора места сохранения
- Расширение файла (.docx или .pdf) будет добавлено автоматически в зависимости от выбранного формата

### 5. Опции
- **Пропустить перевод** - установите галочку, если хотите пропустить автоматический перевод (полезно для тестирования)

### 6. Обработка
- Нажмите кнопку "Обработать" для начала конвертации
- Прогресс выполнения будет отображаться в лог-окне внизу интерфейса
- После завершения вы получите уведомление об успехе или ошибке

## Особенности

- Обработка выполняется в фоновом режиме, интерфейс остается отзывчивым
- Все сообщения о прогрессе отображаются в лог-окне
- При ошибках выводится подробное сообщение с описанием проблемы

## Требования

- Установленный PyQt5 (добавлен в requirements.txt)
- Все зависимости из requirements.txt должны быть установлены

## Установка зависимостей

```bash
pip install -r requirements.txt
```
